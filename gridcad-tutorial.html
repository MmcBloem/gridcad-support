1. What gridCAD electrical does

gridCAD electrical is a CAD workspace for electrical site and project drawings. It combines drawing tools, imported PDFs and DXF files, editable tables, dimensions, annotations, item counting, and project export tools in one iPad or iPhone app.

Use it for

  • Site and project drawing organization.
  • Electrical layouts, schematic-style drawings, and documentation.
  • Imported PDF markup, item counting, and redaction.
  • PDF and DXF output for sharing or downstream CAD workflows.

Main work areas

  • Project Explorer: create sites, projects, tasks, backups, settings, and privacy information.
  • Canvas: draw, edit, import, annotate, count, dimension, and export project content.
  • Sidebars and panels: manage layers, components, symbols, properties, calculations, and tool settings.
Professional review: gridCAD electrical is a drafting, planning, estimating, and documentation tool. Review drawings, dimensions, calculations, item counts, exports, and imported content before fabrication, purchasing, installation, compliance submission, or safety-critical use.

2. Quick start: create your first drawing

  1. Create or open a site. From the project explorer, create a site for the job, customer, building, or project group.
  2. Create a project. Add a project inside the site. Give it a clear name so exports and backups are easy to identify.
  3. Open the canvas. Tap the project to enter the drawing workspace.
  4. Set your grid and snaps. Use the grid and snap controls for clean placement. Endpoint, midpoint, center, intersection, nearest, grid, and ortho snapping can be toggled as needed.
  5. Draw basic geometry. Use Line, Rectangle, Circle, Oval, Polygon, Polyline, Pen, Arc, Spline, Point, or Construction Line from the right toolbar.
  6. Select and edit. Switch to Select, tap or marquee objects, then use property panels, handles, dimensions, or left-toolbar editing tools.
  7. Add labels and dimensions. Use Text, Table, and Dimension tools to document the drawing.
  8. Export or share. Use Export for PDF or DXF output, or save backups from the project/site workflow.

3. Sites, projects, and project records

The project explorer is the starting point for organizing work. A site can contain multiple projects, folders, notes, tasks, and related records.

Create a site

  1. Open the project explorer.
  2. Choose the action to create a new site.
  3. Enter a site name and any job details you want to track.
  4. Save the site.

Create a project

  1. Open a site.
  2. Create a new project.
  3. Add the project name and any project information you want in title blocks or exports.
  4. Open the project to start drawing.

Tasks and notes

Use site and project tasks to track open work, due dates, priorities, tags, and project-specific reminders. Tasks help keep drawing corrections, counts, and follow-up items close to the project they belong to.

Privacy and support

The app includes a Privacy & Disclaimer page from the project explorer. The public privacy policy and support page are available at https://mmcbloem.github.io/gridcad-support/.

4. Canvas basics

Navigation

  • Pan: move around the drawing without moving objects.
  • Zoom: pinch to zoom in and out.
  • View Center: use the view reset/center action when the drawing is hard to locate.
  • Pan tool: switch to Pan mode when you want navigation without editing geometry.

Toolbars

  • Right toolbar: main drawing tools such as Select, Line, Rectangle, Text, Image, Connector, Dimension, Table, and more.
  • Left toolbar: editing tools such as Scale, Offset, Array Copy, Mirror, Trim, Extend, Break, Join, Close, Round Corner, Convert, Merge, Subtract, and Arrange.
  • Top controls: common project actions such as Home, Finish, Copy, Paste, Grid, dimensions display, handles, constraints, appearance, import, export, and settings.
  • Floating panels: tool-specific controls for text, connectors, dimensions, calculations, tables, and other workflows.

Toolbar Explainer

Use the Toolbar Explainer when learning the interface. While it is active, tapping toolbar buttons explains the button instead of running the tool. Turn it off before resuming normal drafting.

5. Drawing tools

Most drawing tools work by selecting the tool, tapping or dragging on the canvas, and finishing the placement gesture. Snapping and ortho settings affect many placement workflows.

  • Select: choose and edit existing objects.
  • Line: draw straight line segments.
  • Rectangle: draw rectangles from one corner to the opposite corner.
  • Circle: draw circles from a center and radius.
  • Oval: draw ovals and ellipses.
  • Polygon: draw regular polygons with configurable side counts.
  • Polyline: draw connected multi-segment paths.
  • Pen: draw Bezier curves with handles.
  • Arc: draw curved arc segments.
  • Spline: draw smooth curves through fit points.
  • Text: place editable text labels and notes.
  • Table: insert editable table grids.
  • Point: place reference point markers.
  • Construction Line: draw infinite dashed reference lines that help align geometry.
  • Connector: draw routed connectors and wires.
  • Spacer: draw spacer runs with managed node spacing and labels.
  • Dimension: place measurement annotations.
  • Image Import: import raster images from Photos or Files.

Polyline and path workflow

  1. Choose Polyline.
  2. Tap each node in sequence.
  3. Use Finish to end the path, or Close to connect the last node back to the first.
  4. Use Join, Round Corner, Offset, Convert, or Anchor Resize for later path editing.

Connector and wire workflow

  1. Open the Connector panel if you need labels, arrows, routing style, or auto wire numbering.
  2. Choose Connector.
  3. Tap the start point and end point. Snapping helps endpoints land exactly on terminals, symbols, or geometry.
  4. Edit routed connector style, labels, arrows, and wire numbering as needed.

6. Snapping, constraints, and dimensions

Snap controls

Snapping helps place points accurately. Enable only the snap types you need for the current task if the drawing is dense.

  • Grid: snap points to the drawing grid.
  • Endpoint: snap to line, path, connector, and object endpoints.
  • Midpoint: snap to the center of compatible segments.
  • Center: snap to circle, oval, and center-based objects.
  • Intersection: snap to crossing geometry.
  • Nearest: snap to the nearest point along compatible geometry.
  • Ortho: lock placement or movement to horizontal and vertical directions.

Constraints

Constraints preserve design intent while editing. Select compatible geometry first, then apply the constraint.

  • Horizontal and Vertical: keep geometry aligned along an axis.
  • Parallel and Perpendicular: maintain direction relationships.
  • Coincident: keep endpoints or points together.
  • Tangent: preserve smooth contact between curves and other entities.
  • Equal: keep compatible lengths or radii equal.
  • Lock: anchor geometry in place for the constraint solver.

Dimension tool

  1. Choose Dimension from the right toolbar.
  2. Set the dimension type, arrows, offset, decimal places, trailing zeros, and measurement scale in the dimension panel.
  3. Tap the first reference point.
  4. Tap the second reference point.
  5. Review the placed dimension text and adjust style or scale if needed.
Tip: snapped reference points create cleaner dimensions. If dimension text is difficult to read, zoom in or adjust text scale and offset from the dimension panel.

7. Selecting and editing objects

Select objects

  • Switch to Select mode before editing existing geometry.
  • Tap an object to select it.
  • Drag a selection area to select multiple objects.
  • Use handles, property panels, or editing tools to modify the selection.

Common editing tools

Transform tools

  • Scale: scale selected geometry around an anchor.
  • Offset: create parallel or expanded copies.
  • Array Copy: duplicate selections into rows, columns, or stepped layouts.
  • Mirror: reflect selected objects across a mirror axis.
  • Arrange: change visual stacking order.

Geometry cleanup

  • Segment Eraser: remove the segment you stroke across.
  • Trim: cut geometry back to target boundaries.
  • Extend: lengthen geometry to another object.
  • Break: split an entity at the crossing point.
  • Join and Close: combine segments or close an open path.
  • Round Corner: soften selected corners.

Boolean and conversion tools

  • Convert to Polylines: turn supported geometry into editable polyline paths.
  • Convert to Wire: convert selected polylines into wire connectors with numbering support.
  • Explode: break compound paths into separate parts.
  • Merge: combine compatible overlapping or adjacent shapes.
  • Subtract: cut selected subtractor shapes out of a main shape.
  • Edit Vector Graphic: restore selected parts of a flattened vector graphic into editable drawing entities.

Undo and redo

Use Undo after accidental edits, unwanted commits, or experiments. Use Redo if you went too far back. Making a new edit can clear some redo history.

8. Layers, symbols, and organization

The layer sidebar helps organize complex drawings. Use layers to group content by purpose, discipline, imported source, sheet, or workflow.

  • Show or hide layers to reduce clutter while drafting, selecting, counting, or exporting.
  • Lock layers to protect finished geometry while working elsewhere.
  • Use non-printable layers for construction guides, temporary markup, or drafting references that should not appear in final exports.
  • Organize imported PDFs and DXF content onto clear layers so source drawings and editable geometry remain manageable.
  • Use symbols and components for reusable graphical components and repeated drawing details.
Dense drawing tip: if selection becomes difficult, hide layers that are not needed for the current task, then turn them back on before final review or export.

9. PDF, DXF, image, and snapshot workflows

Import PDFs

  1. Use the import/sidebar workflow to choose a PDF.
  2. Place the PDF page or pages into the project.
  3. Use layers and names to keep sheets organized.
  4. Annotate, count, redact, trace, or use the PDF as a reference.

PDF pages remain sharp when zoomed, rendered, or exported because the app stores the source PDF data for the project.

Import DXF

  1. Open the Import menu.
  2. Choose a DXF file from Files.
  3. Review imported geometry and layer mapping.
  4. Clean up, edit, convert, or flatten the imported entities as needed.

Import images

  1. Choose Image Import.
  2. Select an image from Photos or Files.
  3. Place it on the canvas.
  4. Switch to Select to move, scale, crop, or arrange it.

Snapshots

Snapshot mode captures a selected canvas area into an image-style object. Use it for reusable visual references or to preserve a region before further editing.

Flattened vector graphics

Flattened vector graphics can improve management of imported or grouped content. If they contain restorable vector payload data, use Edit Vector Graphic to pull selected areas back into normal editable entities.

10. Tables and calculations

Tables

  1. Choose Table from the toolbar.
  2. Tap the canvas to place a default table.
  3. Select the table to edit cells, resize columns and rows, or add and remove rows and columns.
  4. Double-tap a cell to edit its text.
  5. Use property controls for cell text, alignment, and fill.

Electrical calculations

The Calculations panel includes common engineering aids such as power, current, voltage drop, transformer, motor, energy, battery runtime, solar, and panel-builder calculations. Calculators show the result and the basis used for the calculation.

  1. Open Calculations.
  2. Choose the calculation type.
  3. Enter the required values.
  4. Review the result and engineering basis.
  5. Use Insert Table to place an editable calculation table onto the canvas.
Verification: calculation outputs are engineering aids. Always verify final design values against project requirements, manufacturer data, standards, and local rules.

11. Item Counter for PDF pages

Item Counter mode helps count repeated items on imported PDF drawings. It is designed for takeoffs, review, and counted sheet documentation.

Start counting

  1. Select an imported PDF page on the canvas.
  2. Choose Count to enter Item Counter mode.
  3. Draw a selection around the first item you want to count.
  4. Tap matching items on the PDF to add colored marks and increase the count.
  5. Use the sidebar to manage rows, categories, colors, and totals.

Useful Item Counter features

  • New rows: keep similar but separate item types on different rows.
  • Containers: view counts only for checked items inside a named region while the All tab keeps full-page totals.
  • Custom marks: adjust mark size, opacity, and style for different PDF backgrounds.
  • Save to Project: insert the current count table directly onto the canvas.
  • Export counted PDF pages: export the source drawing with selections and manual check marks.
Tip: zoom into small PDF symbols before placing count marks. You can pan and zoom while counting.

12. Annotation and redaction

Annotation mode

Annotation mode is for freehand markup, review comments, highlights, stamps, callouts, and notes that sit over the drawing without changing the underlying CAD geometry.

  • Use annotation tools for review notes and visual comments.
  • Tap an existing matching check mark, X, or stamp again to remove it.
  • Exit annotation mode to return to normal CAD editing.
  • Annotations can appear in PDF exports alongside the drawing.

Redaction mode

Redaction mode is available for selected PDF pages. It lets you obscure sensitive content directly on a PDF page.

  1. Select a PDF page.
  2. Choose Redact.
  3. Draw redaction regions over the content that should be hidden.
  4. Review the page before exporting or sharing.
Important: review redactions carefully before sharing exported documents. Make sure sensitive content is fully covered in the final output.

13. Export, backup, and restore

Export PDF

  1. Open the Export menu.
  2. Choose PDF export.
  3. Select the export scope, page size, scale, and layout options.
  4. Preview the output.
  5. Save or share the PDF.

Export DXF

  1. Open the Export menu.
  2. Choose DXF export.
  3. Choose whether to export the whole drawing or a selected scope.
  4. Open the result in the receiving CAD workflow and verify geometry interpretation.

Backups and restore

  • Use site/project backup workflows to preserve project data.
  • Keep backups before large imports, destructive edits, redactions, or major cleanup sessions.
  • Restoring a site or project adds restored content and does not intentionally delete existing work.
  • Files saved outside the app are controlled by the destination folder, cloud service, or app you selected.

Before sharing a file

  • Review title blocks, notes, dimensions, and layer visibility.
  • Check imported PDFs and images for confidential content.
  • Verify that counted items and calculation tables are correct.
  • Open exported PDF or DXF files in the intended destination workflow to confirm the result.

14. Performance tips for large drawings

  • Hide layers you do not need. Reducing visible content can make selection and navigation easier.
  • Lock finished layers. This prevents accidental edits and simplifies active work.
  • Keep PDFs organized. Name source sheets clearly and place them on sensible layers.
  • Use non-printable layers for guides. Temporary guides can remain helpful without cluttering exports.
  • Flatten complex vector content when appropriate. Flattening can make imported or repeated details easier to manage.
  • Use Edit Vector only where needed. Restore just the area you need to edit rather than expanding entire dense drawings.
  • Adjust performance settings. Use the Settings menu when older devices or very large projects need lighter rendering behavior.
  • Save important outputs back to the project. Generated tables, counted pages, and reference outputs are easier to track when stored with the drawing set.

15. Troubleshooting

I cannot select the right object

  • Zoom in and try again.
  • Hide or lock nearby layers that are not part of the current task.
  • Use isolation mode after selecting the object or group you want to focus on.

Snapping is choosing the wrong point

  • Turn off snap types you do not need for the current operation.
  • Zoom closer to separate nearby snap targets.
  • Use ortho only when horizontal or vertical placement is intended.

An import looks different than expected

  • Check layer mapping and visibility after import.
  • Inspect line styles, fills, text, and scale.
  • For DXF, verify the result in the receiving or source CAD workflow because CAD applications can interpret entities differently.

A drawing feels slow

  • Hide heavy PDF, image, or imported-detail layers while editing other content.
  • Use performance settings for large projects.
  • Split very large jobs into clear sites, projects, layers, or spaces when practical.
